## Bugs found only through real-node tests

- Shard 0 does not serve the message events API in this release. Capture event cursors for message shards only.
- Gasless key changes need signer-state confirmation on this release; relying solely on message-shard merge events incorrectly leaves a successfully registered key pending. Verify KEY_ADD by matching key/nonce; verify KEY_REMOVE by a present-before, absent-after transition.
- The unified signer endpoint wraps gRPC NotFound as HTTP 400. Distinguish that specific error from validation/authentication failures.
- Requester nonce queries require literal `requesterFids[]=3356280`. The encoded brackets generated by URLSearchParams are silently ignored by the node's strict parser, leaving the nonce absent. Preserve literal array brackets; do not default missing nonces to zero.
- Plain-text query errors should be shown as readable errors, rather than a JSON parsing failure.
- Correct the revoked toast so it does not claim that revoked authorization remains active. Explain why an imported key is no longer active.
- Widen mobile FID fields so the actual seven-digit test FID is visible.

## Scope and remaining limitations

The browser wallet path used a local custody signing bridge in automated Chrome; its real signatures were accepted on mainnet. This was not a manual test of a particular wallet extension. The positive recovery-phrase path remains simulated-only because this test custody wallet was generated from a private key, not a mnemonic. No recovery phrase or custody key was sent to the proxy or printed. A registered test app private key was temporarily saved in the ignored mode-600 test secrets directory to verify import; it has since been revoked.

Thirteen automated regression tests pass, including actual API-shaped nonce/NotFound cases. The production build passes; upstream SDK eval and bundle-size warnings remain. Deliberate revoked-key/NotFound requests can generate expected HTTP error console entries; there were no application runtime crashes in the successful live flows. Screenshots and raw sanitized temporary evidence are outside the repository.
